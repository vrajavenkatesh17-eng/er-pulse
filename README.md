# 🚑 ER-Pulse: Tirunelveli Smart Triage & Dynamic Routing

## 🎯 Problem Statement
Tirunelveli corridor traffic (High Grounds / Bypass / Junction) + blind ambulance routing cause hospital ER rejections and fatal golden-hour delays.

## 💡 Solution
Multi-objective decision scoring engine combining **Live ETA + Real-time Free ER/ICU Beds + Specialty Match** (Cardiology/Trauma/General) with instant pre-arrival clinical alerts.

## 🛠️ Tech Stack
- **Frontend / UI**: Streamlit (Dual-panel live command center)
- **Visualization**: Plotly Interactive Spatial Map + Live Table
- **ML / Scoring**: Scikit-Learn (RandomForest) + Multi-criteria Utility Optimization
